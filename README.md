# 🤖 Decode-task1-chatbot

An AI-powered chatbot built with **Python, Streamlit, and Google Gemini API**.

This application provides real-time conversational AI capabilities through a clean and interactive user interface. It uses Google's Gemini large language model to understand user queries and generate intelligent responses.

Developed as part of the **Decode Internship Program (Task 1)**.

---

## 🚀 Features

- ✅ AI-powered conversational chatbot
- ✅ Google Gemini API integration
- ✅ Real-time response generation
- ✅ Interactive Streamlit interface
- ✅ Clean and user-friendly UI
- ✅ Secure API key management using environment variables
- ✅ Natural language understanding

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Generative AI
- Python-dotenv
